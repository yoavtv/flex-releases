# Flex for Android TV / Google TV

Install with the free **Downloader** app (Google Play Store on your TV):

1. Open Downloader and allow it to install apps when asked
   (or: Settings → Apps → Security & restrictions → Unknown sources → Downloader → on).
2. In the address box type: `82-70-255-33.sslip.io/tv`
   (the long way works too: `https://raw.githubusercontent.com/yoavtv/flex-releases/main/tv/Flex-TV.apk`)
3. Press Go → Install → Open.
4. Flex shows a sign-in code: approve it in the Flex app on your computer (Settings → Flex Cloud → Link a TV).
